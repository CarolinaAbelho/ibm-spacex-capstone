# SpaceX Falcon 9 Landing Prediction

## Project Overview

This capstone project analyzes SpaceX Falcon 9 launch data to explore launch outcomes and predict first stage landing success.

The project includes:

* Data collection using APIs and web scraping
* Data wrangling and preprocessing
* Exploratory Data Analysis (EDA)
* SQL analysis
* Interactive visual analytics with Folium and Plotly Dash
* Machine learning classification models

## Objectives

The main objective of this project is to identify factors that influence the success of Falcon 9 first stage landings and build predictive models for landing outcomes.

## Technologies Used

* Python
* Pandas
* NumPy
* SQL
* Folium
* Plotly Dash
* Scikit-learn
* Matplotlib
* Seaborn

## Folium Map Visualizations

GitHub does not fully render interactive Folium map outputs directly inside Jupyter notebooks.
The `folium_maps/` directory contains screenshots of the Folium visualizations developed during the project, including:

* Falcon 9 launch site locations
* Landing outcome visualizations
* Launch site proximity analysis


## Machine Learning Models

The following classification models were evaluated:

* Logistic Regression
* Support Vector Machine (SVM)
* Decision Tree
* K-Nearest Neighbors (KNN)

## Results

The classification models achieved high accuracy on the Falcon 9 test dataset, with Logistic Regression and KNN producing the best overall results.
